# how-to

Step-by-step procedures for things you might need to do on this machine.

**These are not labs.** There is nothing to discover here and nothing to learn — they
exist so a task that is fiddly the first time takes five minutes instead of twenty.
Read one when you need it and ignore the rest.

They are written to be followed exactly, including the parts that look obvious. If a
step says to press a key once, it is because pressing it twice causes a problem
somebody has already had.

If one of these goes wrong, ask. That is faster than reading it a third time.
