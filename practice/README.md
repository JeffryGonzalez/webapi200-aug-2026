# practice

Scratch space. This is where labs happen.

Each lab arrives as its own folder under `labs/`, self-contained, with whatever
starting code it needs. You can do them in any order and skip any of them.

**Break things here.** Nothing in this folder is delivered to anyone, nothing is
graded, and no part of the application depends on it. If a lab tells you to comment out
a line and watch something fail, that is the lab working.

If you want a lab back the way it started: delete its folder and ask for it again.
